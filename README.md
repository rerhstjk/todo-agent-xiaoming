# 小明智能体 · 中文待办清单

[![CI](https://github.com/rerhstjk/todo-agent-xiaoming/actions/workflows/ci.yml/badge.svg)](https://github.com/rerhstjk/todo-agent-xiaoming/actions/workflows/ci.yml)

用中文对话管理待办：说「帮我记一下买牛奶」就新增一条，说「牛奶买好了」就标记完成，
清单会实时同步到一个表格/日历面板。任务保存在本地 JSON 文件里，重启服务不会丢。

这个仓库基于 [TokeNow/todo-agent](https://github.com/TokeNow/todo-agent) 的模板实现：
模板只提供聊天界面、任务 API 和 DeepSeek 客户端，初始的 `reply()` 固定返回一句欢迎语。
本实现补上了智能体、规则引擎、清单面板、日历、提醒和一组离线测试。

## 功能

### 基础要求

- **创建**：`帮我记一下买牛奶` → 新增「买牛奶」；一句话说多件事会拆成多条。
- **查看**：`我有哪些任务？` → 按未完成/已完成列出，带开始时间、优先级、子任务进度；
  也支持「今天」「明天」「本周」「逾期」等范围。
- **完成 / 重开**：`牛奶买好了` → 标记完成；`把牛奶改回未完成` 可以撤回。
- **删除**：`取快递这条删掉吧`，或点清单行尾的 ×；面板 8 秒内可撤销，
  对话里说「撤销刚才的删除」随时可以恢复（服务端保留最近 20 条）。
- **持久化**：任务写入 `data/tasks.json`，刷新页面、重启服务后仍可查询。

### 扩展功能

- **自然语言时间**：明天下午三点、下周一、三分钟后、一个半小时后、昨天补记都能解析；
  「提醒我 5 点开会」里的时间记到开始时间，而不是截止时间。
- **子任务**：添加、完成、删除，清单里可逐条勾选；说「再增加一条子任务」会挂到上一条提到的任务，
  不明确时会追问，不会误建一条新任务。
- **优先级与工作量**：高/中/低；工作量以小时计，用户没说时智能体会追问预计用时。
- **标签**：`#工作` 或「标签：工作、本周」；面板按标签筛选。
- **重复任务**：每天 / 每周 / 每月；完成当前这条后自动生成下一次。
- **清单面板**：表格按「今天 / 明天 / 本周 / 更多」分组，另有逾期、已完成；
  支持搜索（标题/备注/标签）、标签/时间/优先级/工作量组合筛选、批量完成/删除、拖动调宽侧栏。
  点标题或行尾的铅笔可以就地改标题、开始时间、优先级、工作量和备注；
  「手动排序」模式下拖动行首手柄调整顺序，刷新后仍保留。
- **紧急度**：每行左侧按剩余时间着色（逾期红、1 小时内橙、6 小时内琥珀、24 小时内蓝），
  并显示「剩 40 分钟 / 逾期 1 天」，一眼能看出哪些任务最该先处理。
- **固定时区**：日期、时刻、提醒和「今天/明天」统一按 `Asia/Shanghai` 解释，可用
  `XIAOMING_TIMEZONE` 覆盖；部署在 UTC 机器上也不会错一天。
- **月历**：周一起始的整月视图，日期格内直接显示任务条，点某天可查看并勾选。
- **提醒**：任务级开关，设了提醒的任务带铃铛（悬停显示具体时刻）；默认开始前 30 分钟，
  也可以说「提前 10 分钟提醒我」。页面打开时由浏览器发系统通知，页面关闭不会提醒。
- **对话体验**：新建任务没提时间时先问「什么时候要做？」并给快捷选项；回答后依次补齐
  提醒与预计用时，输入框上方会随问题出现「快捷回复」；清单回复在聊天里用卡片列出状态、
  时间与优先级；编辑最新一轮提问（会回滚该轮之前的清单操作并重新生成回复）；多条任务匹配时列出候选让用户回「1/2」；语音输入
  （Chrome/Edge）；输入框上方预设提示词。
- **双引擎**：不配置 `DEEPSEEK_API_KEY` 时走确定性规则引擎；配置后走 DeepSeek 工具调用，
  模型超时或报错会自动回退规则引擎，并避免重复写入。

## 快速开始

需要 Node.js 24.12 或更高版本。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>，直接输入中文即可。**不配置模型密钥也能完整使用**（规则引擎）。

想接入 DeepSeek：把 `.env.example` 复制为 `.env`，填写 `DEEPSEEK_API_KEY`，重启服务。
Windows PowerShell 用 `Copy-Item .env.example .env`。更多细节见[本地开发指南](GETTING_STARTED.md)。

```sh
npm test          # 94 个离线测试：命令层、验收对话、API、模型工具循环、时区
npm run demo      # 不开服务、不花模型费用，在终端跑一遍验收对话与扩展场景

```

GitHub Actions 会在每次推送到 `main` 时跑 `npm ci` → `typecheck` → `test` → `build`
（配置见 `.github/workflows/ci.yml`），公开仓库上可以直接看到绿勾/红叉。

README 里的验收对话就是 `server/agent.test.ts` 的第一条测试，逐句断言清单状态：

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

## 设计与代码导览

智能体分三层：`rules.ts` / `tools.ts` 只是两个适配器，负责把中文或模型工具调用翻译成命令；
`commands.ts` 是唯一的领域层，负责定位任务、判歧义、幂等和安全边界；`replies.ts` 统一渲染中文回复。
所以「同一个操作」在对话、面板、API 三条路径上的语义是一致的。

| 文件                   | 作用                                                  |
| ---------------------- | ----------------------------------------------------- |
| `server/agent.ts`      | 智能体入口：模式选择、DeepSeek 工具循环、回退规则引擎 |
| `server/rules.ts`      | 规则引擎：中文意图、日期/时刻/提醒/标签解析           |
| `server/tools.ts`      | 模型工具定义与参数校验，适配到命令层                  |
| `server/commands.ts`   | 命令层：增删改查、子任务、重复任务、撤销              |
| `server/replies.ts`    | 所有中文回复文案                                      |
| `server/matching.ts`   | 任务名匹配、歧义候选                                  |
| `server/dates.ts`      | 中文日期/时刻/相对时间解析                            |
| `server/selection.ts`  | 时间范围、排序、逾期判断                              |
| `server/timezone.ts`   | 固定时区（默认 Asia/Shanghai）                        |
| `server/task-store.ts` | JSON 持久化（临时文件 + rename 原子写）               |
| `src/App.tsx`          | 聊天界面、消息编辑、提醒开关                          |
| `src/TaskPanel.tsx`    | 表格清单、搜索、筛选、批量操作                        |
| `src/TaskCalendar.tsx` | 月历视图                                              |

架构、数据模型和边界情况的完整说明见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

## 已知限制

- 提醒需要页面保持打开；系统横幅还可能被 macOS 专注模式 / Windows 专注助手拦截。
- 语音输入依赖浏览器语音服务（Chrome/Edge），需要联网和麦克风权限，Firefox 会隐藏入口。
- 单用户、无鉴权，只监听 `127.0.0.1`；多实例部署需要换数据库和锁。
- 撤销与对话快照只存在进程内存（最近 20 条 / 100 个），重启服务后失效。
- 时区固定为 `Asia/Shanghai`（可用 `XIAOMING_TIMEZONE` 覆盖），跨时区协作不在当前范围。
- 真实 DeepSeek 调用只做了离线假模型测试，接入密钥后的效果需要手动体验。
